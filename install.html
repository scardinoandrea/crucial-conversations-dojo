No partner? No problem

Practice solo with Claude

Same cases, same chapter-scoped debrief — Claude takes the other seat. It keeps its own private file, holds its position, and only opens up when you earn it.

1. Install

In the terminal or an IDE extension

  1. Add this repo as a plugin marketplace: 
    /plugin marketplace add scardinoandrea/crucial-conversations-dojo
  2. Install the plugin: 
    /plugin install crucial-conversations@crucial-conversations-dojo
  3. Start a session: 
    /crucial-conversations:dojo
    Or just say “let's practice a crucial conversation”.
  1. In the Claude desktop app, open Cowork, then Customize → Plugins → Add → Add marketplace.
  2. Paste this repo and confirm: 
    https://github.com/scardinoandrea/crucial-conversations-dojo
  3. Go to Discover, pick crucial-conversations, click Install.
  4. Start a task and type /crucial-conversations:dojo, or ask to practice a crucial conversation.
  1. Download the skill:
    ⬇ dojo-skill.zip
  2. In Settings → Capabilities, make sure Create and edit files is on (skills need it).
  3. Open Customize → Skills → + → Create skill → Upload a skill and pick dojo-skill.zip.
  4. In a new chat, say “let's practice a crucial conversation”.

On Team/Enterprise plans an admin may need to allow skill uploads. Uploaded skills don't auto-update — re-download the zip to get new cases. Already installed the plugin via Cowork or Claude Code? Skip this; it's available in chat too.

2. How a session runs

  1. Chapter level — prep, hints and debrief only use tools you've read.
  2. Case — random draw or pick one of the dojo's cases.
  3. Seat — you pick Role A or B and get your private file. Claude takes the other one and never shows it.
  4. Tone — how Claude's character shows up: polite, intimidating, scared, defensive, passive-aggressive, withdrawn, or random (revealed at the end).
  5. Prep, then talk — you open. Claude holds its ground and only shares its hidden facts when you make it safe to.
  6. Debrief — Claude reveals its file and scores you against the checklist, quoting your own words as evidence.
